# Право AI - юридический ассистент (гибридный RAG)

Бэкенд: гибридный поиск (BM25 + FAISS, эмбеддинги BAAI/bge-m3), parent-child чанкинг, реранкинг, защита от промпт-инъекций.
Фронтенд: чат-интерфейс на React с просмотром источников ответа.
Модель генерации: DeepSeek V4.1 Flash через OpenAI-совместимый API.
